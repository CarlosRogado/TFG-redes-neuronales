## Tipos de aprendizaje automático

El **aprendizaje automático** (*machine learning*) es la disciplina que permite a las máquinas aprender sin ser programadas explícitamente. Existen varias estrategias para conseguirlo:

### Aprendizaje supervisado

El modelo entrena con datos etiquetados: cada ejemplo de entrada tiene su respuesta correcta asociada. La red intenta adivinar la respuesta, compara con la real, y ajusta sus pesos para acercarse más la próxima vez.

**Ejemplo**: un dataset de fotos etiquetadas como "perro" o "gato". La red aprende a clasificar nuevas fotos.

### Aprendizaje no supervisado

El modelo recibe datos sin etiquetar y debe encontrar patrones por sí mismo. Es útil para descubrir estructuras ocultas en los datos.

**Ejemplo**: agrupar clientes de una tienda por comportamiento de compra sin conocer las categorías de antemano.

### Aprendizaje autosupervisado

El modelo genera sus propias etiquetas a partir de los datos sin etiquetar. Por ejemplo, ocultar una parte de una imagen y pedirle que la adivine. Se usa cuando hay datos masivos pero sin etiquetar.

### Aprendizaje semisupervisado

Combinación de supervisado y no supervisado: unos pocos datos etiquetados guían el aprendizaje de un conjunto grande sin etiquetar.

### Aprendizaje por refuerzo

Un **agente** aprende a base de interactuar con un entorno y recibir **recompensas** o **castigos**. No se le dice qué hacer, sino que descubre las mejores acciones por prueba y error.

**Ejemplo**: enseñar a un programa a jugar al ajedrez. Gana puntos cuando gana, los pierde cuando pierde.

### ¿Y nuestra simulación?

La simulación de este proyecto utiliza una **combinación** de aprendizaje por refuerzo (los cohetes reciben una "recompensa" por sobrevivir más tiempo) y **algoritmos genéticos** (las mejores redes se seleccionan y mutan para crear la siguiente generación). Esta técnica híbrida se llama **neuroevolución** y la exploraremos en detalle más adelante.
