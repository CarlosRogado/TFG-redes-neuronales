## La red neuronal del proyecto

Hasta ahora hemos hablado de teoría. En esta sección vamos a ver **exactamente** cómo funciona la red neuronal de nuestra simulación.

### Arquitectura concreta

```
Capa de entrada:     6 neuronas  (sin activación)
Capa oculta:         8 neuronas  (activación: ReLU)
Capa de salida:      1 neurona   (activación: sigmoide)
```

Total de parámetros:

$6 \times 8 + 8 = 56$ pesos y sesgos (capa oculta)
$8 \times 1 + 1 = 9$ pesos y sesgos (capa salida)

**Total: 65 parámetros** que evolucionan a lo largo de las generaciones.

### Las 6 entradas

La red recibe **exactamente** estos 6 valores en cada fotograma:

```
1. posY / altura_lienzo
   → Posición vertical del cohete normalizada (0-1)
   → 0 = arriba del todo, 1 = abajo del todo

2. velocidad / 10
   → Velocidad vertical normalizada
   → Valores típicos entre -0.6 y 0.6

3. distanciaX_obstáculo / anchura_lienzo
   → Distancia horizontal al siguiente obstáculo normalizada (0-1)

4. centro_hueco / altura_lienzo
   → Centro del hueco del obstáculo normalizado (0-1)
   → El cohete intenta alinearse con este valor

5. borde_superior_hueco / altura_lienzo
   → Borde superior del hueco normalizado (0-1)
   → La red puede "ver" hasta dónde no llegar

6. borde_inferior_hueco / altura_lienzo
   → Borde inferior del hueco normalizado (0-1)
   → Sabe exactamente el espacio disponible para pasar
```

Normalizar las entradas al rango [0, 1] o [-1, 1] es una práctica estándar en redes neuronales. Ayuda a que el entrenamiento sea más estable y rápido.

### La toma de decisiones (código real)

Cuando un obstáculo se acerca, el cohete ejecuta:

```
Entradas → Red neuronal → Valor entre 0 y 1

Si valor > 0.5 → saltar (aplicar fuerza hacia arriba)
Si valor ≤ 0.5 → no hacer nada (seguir cayendo por gravedad)
```

La red usa una **capa densa oculta con 8 neuronas y activación ReLU**, seguida de una **capa de salida con 1 neurona y activación sigmoide**.

### Creación de la red (TensorFlow.js)

```javascript
const model = tf.sequential({
    layers: [
        tf.layers.dense({
            inputShape: [6],  // 6 entradas
            units: 8,
            activation: 'relu'
        }),
        tf.layers.dense({
            units: 1,
            activation: 'sigmoid'
        })
    ]
});
```

### ¿Por qué esta arquitectura en concreto?

- **6 entradas**: cubren la información esencial para el problema. El cohete sabe dónde está, a qué velocidad va, dónde está el hueco **y el espacio exacto disponible** (bordes superior e inferior). Esto último fue clave: sin los bordes, la red tenía que inferir la altura del hueco a partir del centro; ahora lo sabe directamente.
- **8 neuronas ocultas**: suficientes para aprender el patrón, no tantas como para que el entrenamiento sea lento o sobrequiste.
- **ReLU**: rápida y evita la saturación de gradientes.
- **1 salida sigmoide**: ideal para una decisión binaria (saltar / no saltar) interpretable como probabilidad.

### Las limitaciones de esta red

Esta red es **muy simple** comparada con modelos del mundo real:

- No tiene memoria (no es recurrente), así que no puede aprender secuencias temporales complejas
- Solo ve el obstáculo más cercano, no el siguiente
- No tiene capas suficientes para aprender patrones muy complejos

Sin embargo, es **suficiente** para demostrar el concepto de neuroevolución. Los cohetes aprenden a esquivar obstáculos sin que ningún programador les diga cómo hacerlo.
